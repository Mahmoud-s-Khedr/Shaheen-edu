# Algebra rubric example

Question type: `LONG_ANSWER`. Maximum points: **3**.

Question: حل المعادلة 2س + 3 = 11 موضحًا خطوات الحل، ثم تحقق من إجابتك بالتعويض.

Paste the following text into `gradingRubric`:

```text
الإجابة النموذجية:
نطرح 3 من الطرفين: 2س = 8.
نقسم الطرفين على 2: س = 4.
التحقق بالتعويض: 2 × 4 + 3 = 11، إذن الإجابة تحقق المعادلة.

توزيع الدرجات — المجموع 3 درجات:
1. عزل الحد 2س بصورة صحيحة والوصول إلى 2س = 8: درجة واحدة.
2. القسمة الصحيحة على 2 والوصول إلى س = 4: درجة واحدة.
3. التحقق بالتعويض في المعادلة الأصلية وإظهار أن الطرف الأيسر يساوي 11: درجة واحدة.

البدائل المقبولة:
تقبل أي طريقة جبرية مكافئة توضح التحويلات الصحيحة والنتيجة نفسها.
تقبل الأرقام العربية أو الإنجليزية والرمز x بدلًا من س.

قواعد التصحيح:
تقيّم العناصر الثلاثة بصورة مستقلة.
النتيجة الصحيحة س = 4 وحدها دون خطوات أو تحقق تستحق درجة العنصر الثاني فقط.
إذا كتب الطالب تحويلًا أو تحققًا خاطئًا، فلا تمنح درجة ذلك العنصر.
لا تمنح الدرجة الكاملة لمجرد ذكر النتيجة النهائية.
```

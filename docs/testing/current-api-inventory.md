Negative conventions: absent/invalid bearer is `401`; authenticated wrong role is `403`; malformed DTOs are `400`; missing records are `404`; duplicate or invalid state/version transitions are `409`. Login failures deliberately use generic `401 Invalid credentials`.

No public/student course catalog or content-read route exists. No upload, Bunny, quiz, payment, subscription, AI, import, analytics, or leaderboard controller exists.

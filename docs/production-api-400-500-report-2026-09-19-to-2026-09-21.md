### Root cause

The affected asset, `cmts8hdll007kqf01dzsax5zc`, is referenced by `QuestionImportBatch.sourceAssetId`. PostgreSQL rejected the delete with the `QuestionImportBatch_sourceAssetId_fkey` `RESTRICT` constraint, so the Asset row and remote object were retained.

`AssetsService.isReferenced()` checks `QuestionImportMedia.assetId`, but does not check `QuestionImportBatch.sourceAssetId`. Its pre-check therefore incorrectly permits the delete attempt. PostgreSQL then returns SQLSTATE `23001`; Prisma surfaces it as `PrismaClientUnknownRequestError`, which the global exception filter currently maps to `500` rather than a conflict response.

### Required remediation

1. Add `QuestionImportBatch.sourceAssetId` to `AssetsService.isReferenced()` and its total.
2. Add a test proving that an import-source asset produces `409 Referenced assets cannot be deleted`.
3. Defensively map final database foreign-key deletion failures to `409`, protecting against missed reference checks and concurrent references.
4. Do not delete or archive the affected import-source asset until its import batch no longer requires it.
